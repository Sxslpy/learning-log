# learning-log

记录物联网应用技术专业的学习进度、每日产出和复盘。

## 当前主线

- 主线：2029 年贵州统招专升本
- 副线：AIoT 应用开发（AI + 物联网，偏软件）
- 每日保底：3 小时
- 原则：英语和数学不断线，项目驱动，稳定交付

## 目录

- `plans/`：每周计划
- `logs/`：每日学习日志
- `templates/`：日志与周计划模板

## 使用方式

1. 每周日复制 `templates/weekly-plan.md` 到 `plans/`，命名为 `YYYY-MM-DD-week-NN.md`。
2. 每天复制 `templates/daily-log.md` 到 `logs/`，命名为 `YYYY-MM-DD.md`。
3. 只记录实际完成的内容，不补写、不虚构。
4. 每次学习结束提交一次 Git，至少每周 3 次。
